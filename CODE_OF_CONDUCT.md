# Code of conduct

Be respectful, provide reproducible technical feedback and respect other
people's privacy. Harassment, threats, discrimination and publishing someone
else's private information are not accepted. This applies in the repository
and when representing the project elsewhere.

The maintainer, [mikomiel](https://github.com/mikomiel), handles reports and
may remove content, warn a participant or restrict their participation.
Send private reports through [the repository's private reporting form](https://github.com/mikomiel/privilege-broker/security/advisories/new);
do not include personal details in a public issue. Response is best effort,
not a staffed or time-guaranteed service.

There is no independent project appeal body. If a complaint concerns the
sole maintainer or violates GitHub policy, use GitHub's own reporting route
rather than posting personal information publicly.
